# LTA-SSP

A browsing tool for Singapore's System Security Plan (SSP) controls: find your system type,
browse the full control catalog, or read each system type's profile.

Served via GitHub Pages at https://ziqiangg.github.io/LTA-SSP/ (source: `docs/` on `main`).

To add a new page: create a new folder under `docs/`, add an `index.html` inside it, and use
relative paths for every asset/link (this is a project-path site, not domain root).
