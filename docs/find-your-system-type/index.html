Find your system type

This tool isn't part of the official standard — it's a quick way to build a starting baseline. Tick every characteristic that genuinely applies (a system can be more than one thing at once); the controls shown are computed by combining whichever SSP templates match, taking the strictest requirement wherever they overlap. When unsure, tick more than one and double-check the result against the official pages it links to.
